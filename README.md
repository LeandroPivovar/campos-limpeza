# Campos Limpeza Top - site institucional

Site one-page da **Campos Limpeza Top**: higienização e impermeabilização de estofados (sofás, cadeiras, colchões, interior de carro, tapetes), com atendimento 24 horas.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato, FAQ)
styles.css   # estilos (grafite, vermelho e prata do logo, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.
